# PUS-ViT-Implementation
Source code and datasets for "Physics-Guided Vision Transformer for Interpretable PolSAR Classification" in IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing.
![image](https://github.com/zzd112233/PUS-ViT-Implementation/blob/main/Flowchart/1.png?raw=true)
The paper will be published soon.
# Datasets
Two benchmark PolSAR datasets were utilized to assess the performance of the proposed method in this study.
![image](https://github.com/zzd112233/PUS-ViT-Implementation/blob/main/Flowchart/2.png?raw=true)
# Experimental Configuration
Intel(R) Core(TM) i7-10700 CPU (2.90 GHz) and an NVIDIA GeForce 3060Ti GPU, utilizing PyTorch 3.8.

# Results
To quantitatively measure the proposed method, several evaluation metrics are employed to verify the effectiveness of the algorithm, class-specific accuracy,  macro-averaged recall (Recall),macro-averaged precision (MP), macro-averaged F1-score (F1), overall accuracy (OA), average accuracy (AA), the Kappa coefficient in percent($K100$) and average accuracy (AA) .
